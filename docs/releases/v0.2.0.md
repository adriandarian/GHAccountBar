# GH Account Bar 0.2.0

This release adds account-color customization and formalizes the Apple Silicon release workflow.

## Highlights

- Customize each GitHub account's color for clearer menu swatches and active-account feedback.
- Refresh account state automatically while the menu is open.
- Ship a verified arm64 app bundle for macOS 14 and newer.
- Include a SHA-256 checksum with every release archive.

## Install

1. Download `GHAccountBar-v0.2.0-arm64.zip` from GitHub Releases.
2. Expand the archive and move `GHAccountBar.app` to Applications.
3. On first launch, Control-click the app, choose **Open**, then confirm **Open**.

This free GitHub build is ad-hoc signed and not Apple-notarized, so macOS requires the one-time Control-click launch.

GitHub CLI must already be installed and authenticated. Verify that with `gh auth status`.

## Compatibility

- macOS 14 or newer
- Apple Silicon (arm64)
